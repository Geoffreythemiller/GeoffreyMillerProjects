# Cornell–Philadelphia Bus Site Redesign (INFO 1300)

**Course:** INFO 1300 — Introductory Design and Programming for the Web (Cornell)

## Overview

Static multi-page website redesign for a campus–city bus travel scenario. Focus areas: **clear navigation**, **responsive layout**, and **accessibility-minded** structure (semantic HTML, readable contrast, keyboard-friendly menus).

## Stack

* HTML5
* CSS (`styles/site.css`)
* JavaScript (jQuery 3.7.1 + small custom scripts for navigation and galleries)

## How to open locally

No build step required.

1. Clone [GeoffreyMillerProjects](https://github.com/Geoffreythemiller/GeoffreyMillerProjects) (or open this folder from your copy).
2. Open **`index.html`** in a browser (double-click on Windows, or *File → Open*).
3. Navigate via the site menu to `bus-stops.html`, `bus-schedules.html`, and `tickets.html`.

All asset paths are relative; keep the `scripts/` and `styles/` folders next to the HTML files.

## Pages

# College Pathway Analytics (INFO 4100)

**Status:** Complete academic analytics project — **written report + statistical models in R** (Word document in this folder).

**Course:** INFO 4100 — Learning Analytics (Cornell)

Analysis of **course enrollment trends** and **academic progression patterns** using statistical modeling in R. The project emphasizes cohort thinking, exploratory summaries, and interpretation of model output for instructional and program planning questions—typical of learning-analytics workflows.

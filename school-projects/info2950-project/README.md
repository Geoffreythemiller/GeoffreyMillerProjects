# Sports Performance Prediction (INFO 2950)

**Course:** INFO 2950 — Introduction to Data Science (Cornell)

## Overview

End-of-term data science project applying regression and classification to **professional sports statistics** across multiple leagues. The work emphasizes exploratory analysis, feature engineering, model comparison, and clear reporting of results.

## Skills demonstrated

* Python data workflows (pandas-style analysis in Jupyter)
* Exploratory data analysis and visualization
* Regression and classification models
* Train/test thinking and interpretation of model outputs
* Written communication of findings (report + notebook)

## Artifacts in this folder

| File | Description |
|------|-------------|
| [final_analysis.ipynb](./final_analysis.ipynb) | Reproducible analysis notebook |
| [project-report.pdf](./project-report.pdf) | Final written report |

## Data note

**Academic use only.** Datasets are **public sports statistics** (league box scores and derived features), not proprietary or employer data. Any aggregates in the report are for coursework demonstration.

## How to explore

1. Open `project-report.pdf` for the narrative and figures.
2. Open `final_analysis.ipynb` in Jupyter Lab or VS Code to step through the code (requires a Python environment with common data-science libraries used in the course).
